## 4. 発見した不具合と修正

| # | 内容 | 原因 | 修正 |
|---|---|---|---|
| ① | いいねが「いいねできませんでした [object Object]」で失敗 | `likes` の UPDATE 権限が `status` 列のみのため、`upsert`（ON CONFLICT DO UPDATE で全列更新）が `permission denied` になる。さらに PostgrestError が `Error` ではなく文言化できていなかった | `sendLike` を insert → 23505 時に `status` のみ update へ変更。`errorMessage()` を共通化し PostgrestError も表示 |
| ② | 利用停止 → 有効に戻しても非公開のまま。相手のマッチ一覧で「退会したユーザー」表示 | `admin_set_status` が停止時に `is_public=false` にするが、有効化時に戻していなかった | migration `20260927000800_restore_visibility.sql`: 有効化時 `is_public=true`（実環境適用済み）。表示文言を「非表示のユーザー」に変更。回帰テスト R18b/R18c 追加 |
| ③ | 停止中ユーザーの操作失敗が英語の RLS メッセージ | エラーの文言変換なし | RLS/権限系エラーを日本語化。停止中はアプリ上部に停止中バナー（期限付き）を表示 |

また RLS テストが「DB が空」前提の件数比較になっていたため、実データがある環境でも通るようテスト対象ユーザーにスコープを限定した。
